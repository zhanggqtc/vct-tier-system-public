# VALORANT 赛事现场掉落体系（合作方对外版）

VCT（VALORANT Champions Tour）四级赛事现场掉落规则、奖品搭配和数据汇总。

## 在线浏览

启用 GitHub Pages 后访问：https://zhanggqtc.github.io/vct-tier-system-public/

## 内容

- VCT 全年 4 档赛事一览（冠军赛 / 大师赛 / 巡回赛季后赛 / 季中赛+启点赛）
- 数据汇总表：单场观众、票价均价、中奖率、单次中奖均价、场次
- 常规方案：每局 3 次固定掉落（手枪局 / 半场 / 赛后）
- Buff 加场：高峰日全区掉落规则
- 营销话术建议（按等级）

## 数据口径

- 数据来源：VCT 赛事公开开票 + VALORANT 国服奖品公开售价
- 票价 / 中奖率 / 中奖期望已向上取整便于对外沟通
- 高峰日封顶：单日总中奖率 ≤ 40%（常规 + 全区加场）
